# BTC·ETH 바이낸스 선물 데모 자동매매 · 안드로이드 앱

원본 `btcusdt_rsi_demo.py`의 전략·주문·백테스트 로직(`core.py`)을 그대로 쓰고,
화면만 모바일용(Kivy, `main.py`)으로 새로 만들었습니다. **바이낸스 데모 서버 전용**입니다.

## APK 만드는 방법 (PC 없이 가능, 무료)
1. GitHub에서 새 저장소(private 권장)를 만들고 이 폴더의 모든 파일을 올립니다.
2. 저장소의 **Actions → Build Android APK → Run workflow** 를 누릅니다. (첫 빌드는 20~40분)
3. 완료되면 같은 화면 아래 **Artifacts → rsi-demo-apk** 를 내려받아 압축을 풀고 `.apk`를 폰에 설치합니다.
   (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

Linux/WSL에서 직접 빌드: `pip install buildozer cython==0.29.36` 후 `buildozer android debug`

## 사용법
- 설정 탭: 방향/봉/종목, 롱·숏 주문 및 RSI 조건, 데모 API Key·Secret 입력
- 실행 탭: 설정 적용 → 연결 확인 → 데모 시작 / 중지 / 시장가 즉시 진입
- 기록 탭: 저장된 백테스트 순위

## 백그라운드 실행 (버전 12)
- **데모 시작**을 누르면 자동매매가 안드로이드 **포그라운드 서비스**(`service.py`)로 따로 실행됩니다.
  화면을 끄거나, 홈 버튼·뒤로 가기로 나가거나, 최근 앱 목록에서 앱을 밀어 닫아도 계속 돌아갑니다.
- 실행 중에는 상단에 **"자동매매 실행 중"** 알림이 표시됩니다. 알림을 누르면 앱이 열리고,
  실행 상태와 로그를 이어서 보여 줍니다. 멈추려면 앱의 **중지** 버튼을 누르세요.
- 처음 시작할 때 **알림 권한**과 **배터리 최적화 제외**를 묻습니다. 둘 다 허용하세요.
  삼성 폰은 `설정 → 배터리 → 백그라운드 사용 한도`에서 이 앱을 "절전 예외 앱"에 넣는 것도 권장합니다.
- 시스템이 메모리 부족 등으로 서비스를 강제로 끝내면, 안드로이드가 다시 띄울 때 저장된 설정으로
  자동매매를 이어갑니다(네트워크가 없으면 30초 간격으로 재연결 시도).
- 연결 확인·백테스트·자동매매가 꺼진 상태의 시장가 즉시 진입은 예전처럼 앱 화면에서 실행됩니다.
- 구조: `main.py`(화면) ↔ `bridge.py`(앱 전용 폴더의 파일로 명령·상태·로그 전달) ↔ `service.py`(매매) → `core.py`(전략·주문)

## 꼭 알아둘 점
- 폰이 꺼지거나 인터넷이 끊기면 자동매매도 멈춥니다. 이미 접수된 손절·익절 주문은 거래소에 남습니다.
- 백그라운드 실행 중에는 API 키가 앱 전용 저장 공간(`service/job.pickle`)에 임시 저장되고, 중지하면 삭제됩니다.
  키 저장 기능도 평문(JSON)이므로 **데모 키만** 사용하세요.
- `android.api = 34` 기준입니다. 나중에 35 이상으로 올리면 안드로이드 15의 dataSync 서비스 하루 6시간 제한이
  적용되므로 서비스 종류를 바꿔야 합니다.
- 실제 기기 테스트는 아직 하지 않았습니다. 첫 실행 후 문제가 있으면 알려 주세요.
