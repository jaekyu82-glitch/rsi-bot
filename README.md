# BTC·ETH 바이낸스 선물 데모 자동매매 · 안드로이드 앱

원본 `btcusdt_rsi_demo.py`의 전략·주문·백테스트 로직(`core.py`)을 그대로 쓰고,
화면만 모바일용(Kivy, `main.py`)으로 새로 만들었습니다. **바이낸스 데모 서버 전용**입니다.

## APK 만드는 방법 (PC 없이 가능, 무료)
1. GitHub에서 새 저장소(private 권장)를 만들고 이 폴더의 모든 파일을 올립니다.
2. 저장소의 **Actions → Build Android APK → Run workflow** 를 누릅니다. (첫 빌드는 20~40분)
3. 완료되면 같은 화면 아래 **Artifacts → rsi-demo-apk** 를 내려받아 압축을 풀고 `.apk`를 폰에 설치합니다.
   (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

Linux/WSL에서 직접 빌드: `pip install buildozer cython==0.29.36` 후 `buildozer android debug`

## 사용법
- 설정 탭: 방향/봉/종목, 롱·숏 주문 및 RSI 조건, 데모 API Key·Secret 입력
- 실행 탭: 설정 적용 → 연결 확인 → 데모 시작 / 중지 / 시장가 즉시 진입
- 기록 탭: 저장된 백테스트 순위

## 꼭 알아둘 점
- 자동매매 중에는 **앱을 켜 둔 상태**(화면 켜짐 유지)여야 합니다. 안드로이드가 백그라운드 앱을 종료할 수 있어
  배터리 최적화 제외를 권장합니다. 앱이 꺼져도 이미 접수된 손절·익절 주문은 거래소에 남습니다.
- 키 저장은 선택 사항이며 앱 전용 저장 공간에 평문(JSON)으로 저장됩니다. **데모 키만** 사용하세요.
- 실제 기기 테스트는 아직 하지 않았습니다. 첫 실행 후 문제가 있으면 알려 주세요.
